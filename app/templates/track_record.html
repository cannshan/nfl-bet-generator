Closing line value (CLV)

Did this app's suggested price beat the market's own closing line? Sharp bettors treat CLV as a faster, more reliable skill signal than win/loss — it only needs the line to move, not the game to be played, and it's how sportsbooks themselves spot sharp customers. Captured opportunistically whenever this page loads before a game's kickoff, so it's an approximation of the true closing number, not a continuously-polled snapshot.
